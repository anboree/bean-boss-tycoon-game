# WEBSITE SETUP

**1.** Download project as zip\
**2.** Extract zip folder\
**3.** Open XAMPP\
**4.** Start Apache and MySQL servers\
**5.** Open localhost/phpmyadmin in web browser\
**6.** Create database named - bean_boss_tycoon_game\
**7.** Set collation to utf8_general_ci\
**8.** Press 'Create' button\
**9.** Press 'Import' in the top navbar\
**10.** Press 'Browse' and select the bean_boss_tycoon_game.sql file from the extracted project folder\
**11.** Press 'Import'\
**12.** Database is set up!
